# Rapport LaTeX

## Compilation

```bash
latexmk -pdf main.tex
```

Ou :

```bash
pdflatex main.tex
pdflatex main.tex
```

## Redaction

Chaque membre redige sa partie dans un fichier distinct :

- `sections/01_setup.tex` : Abdellah
- `sections/02_clients.tex` : Reda
- `sections/03_consommation.tex` : Nafisa et Nizar
- `sections/04_facturation.tex` : Aymen
- `sections/05_tests.tex` : Aymen et Abdellah
- `sections/06_conclusion.tex` : toute l'equipe

Les figures sont placees dans `figures/`.
