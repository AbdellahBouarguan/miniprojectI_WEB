\section{Installation et organisation du projet}

\subsection{Environnement}

Le projet utilise PHP, MariaDB et Apache.

\subsection{Base de donnees}

La base de donnees \texttt{miniproject\_version\_alpha} contient les tables suivantes : \texttt{fournisseur}, \texttt{client}, \texttt{tarif}, \texttt{consommation}, \texttt{photo\_capteur}, \texttt{anomalie} et \texttt{facture}.

\subsection{Organisation Git}

Le depot Git est organise autour de la branche \texttt{main}. Chaque fonctionnalite est developpee dans une branche dediee puis integree par une Pull Request.
