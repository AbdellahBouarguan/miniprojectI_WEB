\section*{Glossaire}
\addcontentsline{toc}{section}{Glossaire}

\begin{description}[leftmargin=3.2cm,style=nextline]
  \item[API] Interface de programmation permettant à des composants de communiquer.
  \item[CRUD] Créer, lire, mettre à jour et supprimer des données.
  \item[CSRF] Falsification de requête intersite ; protection par jeton pour les formulaires.
  \item[FK] Clé étrangère assurant l'intégrité référentielle entre deux tables.
  \item[IHM] Interface homme-machine, c'est-à-dire la couche de présentation.
  \item[MVC] Modèle--Vue--Contrôleur, architecture séparant données, présentation et traitement.
  \item[PDO] PHP Data Objects, extension d'accès aux bases de données.
  \item[SGBD] Système de gestion de base de données.
  \item[TVA] Taxe sur la valeur ajoutée, fixée à 18 \% dans le projet.
  \item[XSS] Injection de code HTML ou JavaScript dans une page.
\end{description}
