\section*{Résumé}
\addcontentsline{toc}{section}{Résumé}

\textbf{AquaVolt} est une application web de gestion des consommations d'eau et d'électricité et de leurs factures. Développée en PHP 8 avec une base MariaDB, elle repose sur une architecture MVC qui sépare l'accès aux données, le traitement métier et l'interface utilisateur.

La version Alpha couvre trois fonctionnalités principales : la gestion des clients, la saisie des consommations avec téléversement des photos des compteurs, et la gestion des factures. Elle propose également l'authentification des clients et du fournisseur, la détection des anomalies de saisie, un flux de confirmation ou de correction, ainsi que la génération automatique et la consultation des factures.

Le rapport présente le contexte du projet, l'analyse des besoins, l'architecture, le modèle de données, les modules réalisés, les mécanismes de sécurité, les tests effectués et les perspectives d'évolution.

\vspace{0.5cm}
\noindent\textbf{Mots-clés :} PHP, MariaDB, MVC, consommation, facturation, anomalies, sécurité, application web.

\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

\textbf{AquaVolt} is a web application for managing water and electricity consumption and the related invoices. It is developed in PHP 8 with a MariaDB database and follows an MVC architecture that separates data access, business logic and the user interface.

The Alpha version covers three main features: customer management, monthly consumption entry with meter photographs, and invoice management. It also provides role-based authentication, anomaly detection, a confirmation or correction workflow, and automatic invoice generation and consultation.

This report describes the project context, requirements analysis, architecture, data model, implemented modules, security mechanisms, tests and future improvements.

\vspace{0.5cm}
\noindent\textbf{Keywords:} PHP, MariaDB, MVC, consumption, billing, anomalies, security, web application.
