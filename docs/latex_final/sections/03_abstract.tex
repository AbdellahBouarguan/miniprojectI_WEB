
\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\textbf{AquaVolt} is a web application dedicated to managing water and electricity consumption and monitoring the corresponding bills. Developed using PHP 8 and a MariaDB database, it follows the Model--View--Controller (MVC) architecture, which separates data access, business logic and the user interface.

The final version provides several features, including customer and district management, monthly consumption entry with meter photograph uploads, automatic anomaly detection and processing, and invoice generation. It also includes complaint management, payment recording, annual consumption data import and verification, internal notifications, and a dashboard designed to monitor the supplier's activities.

This report presents the different stages of the project, from requirements analysis and architectural design to the development of the various modules and their validation. It also describes the security mechanisms implemented, the tests performed and the future improvements planned for the application.
